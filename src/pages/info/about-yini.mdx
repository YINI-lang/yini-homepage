# About YINI — An INI-Inspired Configuration Format

**YINI** is an INI-inspired text-based data format designed for **clarity**, **simple section nesting**, and **predictable parsing**.

<a href="/get-started" class="btn btn-primary">
    {' '}
    Get Started{' '}
</a>

YINI is a practical rethink of classic INI: the same friendly feel, but with **real structure**—sections, arrays (lists), objects, and clear rules — while remaining easy to read and write.

The format's syntax and behavior are defined in the **YINI Specification**, which provides a formal and consistent foundation for implementations.

YINI is created and maintained by Marko K. Seppänen as an open-source project under the **YINI-lang** organization on GitHub, with ongoing refinement and tooling improvements.
