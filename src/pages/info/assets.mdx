# YINI Logos & Assets

Official YINI brand assets, logos, favicons, and media kit materials will be
collected here.

## Usage Guidelines

When referring to YINI, please keep the name uppercase and describe it as a
human-readable configuration format designed for clarity, or as a structured text format.

Write the name as `YINI` when referring to the format. In technical contexts that require lowercase (such as package names, commands, or filenames) use `yini` instead of `Yini`.

## Short Description

YINI is an INI-inspired configuration format designed for clarity,
explicit structure, and predictable parsing.

## Project Link

- [YINI Project on GitHub ↗](https://github.com/YINI-lang/YINI-spec)
